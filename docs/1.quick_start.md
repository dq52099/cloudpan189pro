# CloudPan189Pro 快速开始

## Docker Compose（推荐）

PostgreSQL 版：

```bash
git clone https://github.com/dq52099/cloudpan189pro.git
cd cloudpan189pro
docker compose up -d
```

默认访问地址：

- Web 界面：`http://localhost:12395`
- WebDAV：`http://localhost:12395/dav`

`docker-compose.yml` 使用 `etc/config.docker.yaml`，数据库会连接到同一个 compose 网络中的 `postgres` 服务。

## SQLite 版

```bash
git clone https://github.com/dq52099/cloudpan189pro.git
cd cloudpan189pro
cp etc/config.example.yaml etc/config.yaml
docker compose -f docker-compose.sqlite.yml up -d
```

## Docker Run

```bash
mkdir -p data logs media_dir
docker run -d \
  --name cloudpan189pro \
  -p 12395:12395 \
  -v "$PWD/data:/app/data" \
  -v "$PWD/logs:/app/logs" \
  -v "$PWD/media_dir:/app/media_dir" \
  --restart unless-stopped \
  dq52099/cloudpan189pro:latest
```

## 本地构建

```bash
make build
./output/share -config etc/config.yaml
```

前置依赖：

- Go 1.25+
- Node.js 22+
- Corepack

## 初始化

1. 打开 `http://localhost:12395`。
2. 完成初始管理员设置。
3. 在“令牌管理”添加天翼云盘令牌。
4. 在“存储管理”添加挂载点。
